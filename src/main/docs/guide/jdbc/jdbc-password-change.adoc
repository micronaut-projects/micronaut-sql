If some data sources have logic for password rotating and changing in run time there is
link:{api}/io/micronaut/jdbc/DataSourcePasswordChangedEvent.html[DataSourcePasswordChangedEvent] event that
can be published and it will trigger data source with given name to update password:

[source,java]
----
applicationContext.publishEvent(new DataSourcePasswordChangedEvent(new DataSourcePasswordChangedEvent.DataSourcePasswordModel("default", "newpassword")));
----

In this example `default` is datasource name.
