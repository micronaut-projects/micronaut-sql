https://docs.oracle.com/en/database/oracle/oracle-database/26/jjdbc/JDBC-service-provider-extensions.html[JDBC Service Provider Extensions]

____
Starting with Oracle AI Database Release 26ai, you can extend the capabilities of Oracle JDBC drivers through service providers.
____

https://github.com/oracle/ojdbc-extensions/[Oracle JDBC Driver Extensions] are service providers that the Oracle JDBC driver loads from the classpath. There are two kinds:

* *Configuration providers* supply a whole connection configuration, including the connect descriptor, user and password, from a file, an HTTPS server, OCI Object Storage, OCI Database Tools, Azure App Configuration and other sources. The data source URL names the provider.
* *Resource providers* supply one value, such as a password, an access token, a connection string, a TLS configuration or a trace event listener. They are configured with connection properties.

Micronaut SQL manages the versions of the provider artifacts, so you can add them without a version:

dependency:ojdbc-provider-oci[groupId="com.oracle.database.jdbc"]

The managed artifacts are `ojdbc-provider-common`, `ojdbc-provider-oci`, `ojdbc-provider-azure`, `ojdbc-provider-aws`, `ojdbc-provider-gcp`, `ojdbc-provider-hashicorp`, `ojdbc-provider-jackson-oson` and `ojdbc-provider-observability`. The providers depend on the Oracle wallet library, `com.oracle.database.security:oraclepki`, which is managed at the version of the driver.

=== Configuration providers

With a configuration provider, the data source needs only a URL of the form `jdbc:oracle:thin:@config-<provider>://<location>`. The built-in `file` provider reads a JSON file:

[configuration]
----
datasources:
  default:
    url: jdbc:oracle:thin:@config-file:///etc/myapp/oracle-config.json
----

[source,json]
----
{
  "connect_descriptor": "dbhost:1521/orders",
  "user": "app",
  "password": {"type": "base64", "value": "c2VjcmV0"}
}
----

Other providers follow the same pattern, for example `jdbc:oracle:thin:@config-ociobject://mytenancy.objectstorage.us-phoenix-1.oci.customer-oci.com/n/mytenancy/b/bucket1/o/payload.json` or `jdbc:oracle:thin:@config-azure://myappconfig?key=/sales_app1/&label=dev`. See the https://github.com/oracle/ojdbc-extensions/[Oracle JDBC Driver Extensions] documentation for the options of each provider.

TIP: With Oracle UCP, settings that take Java objects rather than values, such as a token supplier, are configured with a api:configuration.jdbc.ucp.PoolDataSourceCustomizer[] instead.
