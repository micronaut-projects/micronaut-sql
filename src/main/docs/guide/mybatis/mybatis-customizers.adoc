You can define additional beans which will be used when the MyBatis `Configuration` is created.
Only beans of type api:configuration.mybatis.MyBatisConfigurationCustomizer[] with a `Named` qualifier matching the datasource name will be applied.

Micronaut also looks for a link:https://mybatis.org/mybatis-3/apidocs/org/apache/ibatis/transaction/TransactionFactory.html[TransactionFactory] bean qualified with the datasource name. If none is present, Micronaut falls back to link:https://mybatis.org/mybatis-3/apidocs/org/apache/ibatis/transaction/jdbc/JdbcTransactionFactory.html[JdbcTransactionFactory].

For example, you can register mapper interfaces and tune MyBatis settings for a specific datasource:

This hook is also the right place to configure other MyBatis features that belong on the `Configuration`, such as type aliases, type handlers, interceptors, or additional mapper registrations.
