Micronaut supports the reactive and non-blocking https://vertx.io/docs/vertx-oracle-client/java/[Vert.x Oracle client], which runs on the asynchronous API of the Oracle JDBC driver.

To use it, add the `vertx-oracle-client` module to your classpath:

dependency:micronaut-vertx-oracle-client[groupId="io.micronaut.sql"]

The module depends on the same Oracle JDBC driver (`ojdbc17`) as the other Micronaut SQL modules, instead of the older `ojdbc11` release the Vert.x Oracle client declares.

Then configure the https://vertx.io/docs/vertx-oracle-client/java/[`OracleConnectOptions` and `PoolOptions`] of the database:

[configuration]
----
vertx:
  oracle:
    client:
      host: the-host
      port: 1521
      service-name: FREEPDB1
      user: test
      password: test
      max-size: 5
----

You can also set `uri`, for example `oracle:thin:@the-host:1521/FREEPDB1`, instead of the host, port and service name. When the URI has no credentials, the configured `user` and `password` are used.

The module then provides an `io.vertx.sqlclient.Pool` bean, which you can inject to run queries:

snippet::io.micronaut.docs.vertx.oracle.BookCatalog[tags="imports,clazz"]

<1> The `Pool` bean configured by the `vertx.oracle.client` properties
<2> A prepared query with a bind parameter, executed without blocking

For more information on running queries with the reactive client, read the https://vertx.io/docs/vertx-oracle-client/java/[vertx-oracle-client] documentation.
